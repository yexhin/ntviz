# NTViz: Next-Gen Data Visualization Recommendation System


## ✍ Description:
In today's data-driven world, decisions across not only the technology sector but also fields like economics, finance, and journalism are increasingly shaped by data. Yet, have you ever wondered how we can uncover insights just by looking at raw data? This remains a significant challenge, even for professionals.

Data visualization is a powerful tool that helps bridge this gap. However, for non-technical users, creating the right visualizations can be daunting.

**NTViz** is a next-generation data visualization recommendation system designed to solve this problem. It automatically suggests the most suitable chart types based on the user's dataset and intent. Our system builds upon and extends the capabilities of the open-source library **LIDA**.
